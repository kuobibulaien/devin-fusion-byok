# Devin Fusion BYOK

独立的 Devin 用户扩展。使用启动时的内存接口和仅对 Devin CLI 生效的本地连接服务，在原生模型列表加入第三方模型和 Fusion 组合。

应用包不做修改，不需要重新签名。扩展保存在 `~/.devin/extensions`，配置保存在 Devin 的用户扩展存储目录。

## 使用

安装 VSIX 后，新建 Devin 窗口。点击右下角状态栏 **Fusion BYOK**，或按 `⌘⇧P` 运行 **Fusion BYOK：控制面板**。

控制面板支持添加、编辑、停用和删除多个供应商。填写供应商名称、兼容 API 地址、密钥，并选择 Responses 或 Chat Completions；编辑时密钥留空会保留原值，页面不会回显已保存的密钥。

选择供应商后，点击 **选择模型导入** 获取可用模型列表。新模型默认不勾选；搜索并勾选需要的模型，点击 **导入所选模型** 才会保存。支持全选当前搜索结果和清空选择；取消不会导入任何模型。已有模型标记为“已导入”，不会重复添加、删除或改变启停状态。

导入后可以搜索、批量勾选启停、手动添加模型 ID，并编辑显示名称、上下文长度和推理强度。模型行上的 **删除** 会先弹出确认框，确认后才移除该模型；取消或关闭对话框不会删除任何模型。命令面板的 **Fusion BYOK：选择模型导入** 也会打开此管理页面。

新导入或手动添加的模型默认上下文为 **272,000 tokens**，最大输出为 **32,768 tokens**；可逐个修改。

在 **我的 Fusion 预设 → 新建预设** 中填写名称，分别选择 Lead、Sidekick 及其档位。可以保存多个预设，之后编辑、改名、删除或选择。只有保存且当前可用的预设才生成模型入口，不再自动穷举组合。每个预设拥有独立、稳定的模型标识，按保存顺序显示在原生模型列表的 **我的 Fusion** 首位分组；第三方单模型仍可独立调用。

Lead／Sidekick 两份角色列表独立管理，默认包含全部已启用的第三方模型及官方目录证明可用于对应角色的模型，只作为创建预设时的候选范围。从某角色移除模型不会删除供应商模型或影响另一角色。依赖不可用模型的预设保留并显示原因，不再发布可选入口；模型重新可用后恢复。官方模型不会因本地预设而获得账号原本没有的权限。

升级时会尝试把原先保存的默认组合准确还原为 **原默认组合** 预设；缺少官方目录信息时等待同步，不随意替换型号。明确删除全部预设后不会自动重建。保存配置不会自动重连或中断正在运行的会话；原生列表需要会话刷新目录才能显示新预设。

面板的 **官方模型** 区域列出 Devin 当前上报的原生模型，支持按名称或 UID 搜索，并标注“显示中 / 已移除”、官方不可用标记，以及是否“可作 Sidekick”。点 **移除** 只在本机把该条目从收到的目录中隐藏：不修改官方服务端配置，不改账号权限，其余官方条目保持原样。已移除的条目仍留在面板中便于加回；点 **加回** 只是删除本机的隐藏记录，模型要等 Devin 再次上报后才重新出现在列表里——扩展不会凭本地记录凭空补回官方已停发的条目。Devin 尚未上报任何官方模型时，该区域显示“等待 Devin 刷新官方模型列表”。

GPT-5/6 和 o1/o3/o4 的基础模型 ID 在未设置档位时，自动提供 Low、Medium、High、XHigh 预设；带固定强度后缀的模型和其他系列继续使用供应商默认。可以在 **编辑模型 → 思考程度设置** 中手动填写供应商支持的档位，或选择不指定程度。预设来自模型 ID 规则，并非 `/models` 的能力检测；当前 `load / gpt-6-astra` 的 High 已通过真实请求验证。选择的档位会传入 Responses 的 `reasoning.effort` 或 Chat Completions 的 `reasoning_effort`。原来的默认档位 UID 保留，不指定参数时仍沿用供应商默认。

所有导入模型始终声明支持图片输入；早期配置中的关闭值同样按开启处理。这只是能力声明，不是供应商能力检测或保证。官方 Lead 的图片能力仍以官方目录为准。官方候选必须由已观察到的可用 Fusion 组合证明角色资格，并使用其实际执行通道；不再退回仅凭 SWE 通道识别型号。Fast Mode 变体、精确 UID 对应失败、序号或名称冲突、账号禁用、元数据歧义均不能授予资格。支持第三方／官方在两个角色中组合，但每个原生角色都必须满足上述条件和团队允许列表。没有收到官方目录时，仅含第三方模型的预设仍可使用。

已有 `~/.cwindsurf/providers.json` 时自动导入配置。原有 **Fusion BYOK：配置第三方 API** 命令现在也打开控制面板。

在原生模型列表的 **我的 Fusion** 分组直接选择预设，也可运行 **Fusion BYOK：选择 Fusion 预设** 或使用面板中的“选择”。选中的预设会被记住：当原生模型选择被重置为官方 Fusion 或清空时，扩展自动恢复有效的已记住预设；选择普通单模型不会被覆盖。改名保留选择标识；删除或停用导致预设不可用时不会强行恢复。

在控制面板中可独立开启两项自动继续选项（均默认关闭）：
- **遇到服务商错误时自动继续回复**：当模型回复以“Provider response could not be completed”结尾或返回临时网络错误（如 HTTP 429/500/502/503/504 等）时，插件自动发送 `continue` 尝试继续，并在界面显示对应提示。关闭开关会立即取消后续自动继续；首次安装后请重新加载窗口并新建会话，以接入本地连接。重试间隔从 2 秒逐步增加，最长 30 秒；仅匹配指定失败提示，不判断任务是否完成，也不修复供应商故障。
- **有未完成待办时自动继续**：当检测到会话中存在未完成的结构化待办（Plan/Todo）时，每轮正常回复后自动发送 `continue` 推进执行，直到全部待办完成或被停止打断。插件仅基于会话中的结构化待办状态判断，不保证业务语义上的真正完工；无待办、非结构化计划或用户被询问权限时不会自动盲目继续。使用计费模型时请留意连续调用产生的额外用量。

免费账号无法调用的官方能力不会被解锁。插件根据角色管理和官方可用状态过滤 Fusion 目录，不修改官方权限。已有的锁定官方选择兼容回退仅在记住的预设两个角色都为第三方模型且仍有效时生效；建议直接选择自己命名的预设。原生选择器的固定收藏、最近使用等系统区域由 Devin 管理，插件保证注入的模型分组中“我的 Fusion”排在最前，不修改客户端应用。

## 保存和更新

密钥仅保存在用户私有配置文件（权限 0600）。日志仅记录模型名、工具名和连接状态。通过 `devin.acp.agentEnv` 给 Devin CLI 设置 `WINDSURF_API_SERVER_URL`，只连接本机服务；本机服务仍通过正常 HTTPS 访问官方接口。不安装证书，不修改系统代理。

Devin 常规应用更新不会覆盖用户扩展目录。扩展每次启动重新寻找内置扩展和语言服务。若 Devin 未来移除当前运行时接口，扩展会报告错误；这不等于保证兼容所有未来版本。

扩展版本更新后，本机连接服务在下次启动时平滑替换。如果同目录下的旧版服务仍在处理请求，扩展会先直接沿用旧服务完成启动，升级在后台继续等待；旧服务空闲后才做带归属校验的停机替换，正在进行的请求不会被强行中断，期间日志记录 `runtime-update-pending`。属于其他配置目录或更新版本的服务不会被视为可复用，仍按原逻辑报错。

## 停用

先运行 **Fusion BYOK：停用并恢复连接**，再卸载扩展。停用会撤回所有窗口的模型注入，并恢复本扩展设置的 CLI 环境项和默认 Fusion 组合。环境项只在当前值仍等于插件所写值时恢复；默认模型有原始备份且当前仍属于本插件时才恢复，保留用户之后选择的原生模型。关闭或重新加载普通窗口只清理该窗口的注入，不会撤回其他窗口所需的连接设置。停用后可通过 **配置第三方 API** 重新启用；单独刷新模型不会重新启用。

直接卸载也会尝试恢复已记录的设置，兼容 JSONC 注释和尾随逗号，并保留原设置副本。若设置内容有歧义、正在被修改或无法安全写入，脚本不覆盖它，并把恢复记录保存在用户 `settings.json.fusion-byok-restore-pending.json`。卸载脚本的执行时间由 Devin 限制；先运行恢复命令更可靠。

已经启动的会话沿用启动时的环境；停用后请新建会话使用原生配置。本地服务不会因关闭一个窗口或卸载而强行终止正在进行的请求。
