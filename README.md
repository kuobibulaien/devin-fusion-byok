# Devin Fusion BYOK

独立的 Devin 用户扩展。使用启动时的内存接口和仅对 Devin CLI 生效的本地连接服务，在原生模型列表加入第三方模型和 Fusion 组合。

应用包不做修改，不需要重新签名。扩展保存在 `~/.devin/extensions`，配置保存在 Devin 的用户扩展存储目录。

## 使用

安装 VSIX 后，新建 Devin 窗口。点击右下角状态栏 **Fusion BYOK**，或按 `⌘⇧P` 运行 **Fusion BYOK：控制面板**。

控制面板分四个标签页：**预设**（常用，默认打开）、**模型**（供应商与导入的模型）、**用量**（请求统计）、**设置**（自动继续、预设可选模型、官方模型显示、插件更新）。右上角是 **重启 Devin** 按钮和启用整个插件的开关。所有开关即改即存，删除操作收在各自的编辑弹窗里并需二次确认。

**模型** 页支持添加、编辑、停用和删除多个供应商。填写供应商名称、兼容 API 地址、密钥，并选择 OpenAI Responses、OpenAI Chat Completions 或 Anthropic Messages；编辑时密钥留空会保留原值，页面不会回显已保存的密钥。

API 地址只填域名时自动补上 `/v1`；路径里已有版本段（如 `/v1`、`/v4`、`/v1beta`）则按原样使用，粘贴进来的 `/responses`、`/chat/completions`、`/messages`、`/models` 后缀会被去掉。弹窗在地址下方实时显示实际请求地址和模型列表地址。

Anthropic Messages 供应商使用 `x-api-key` 与 `anthropic-version: 2023-06-01` 请求头，请求发往 `<API 地址>/messages`，模型列表按 Anthropic 分页读取并采用返回的上下文与最大输出上限。当前取舍：思考档位写入 `output_config.effort`，不主动发送 `thinking` 参数（新模型默认自适应思考，思考内容是否可见取决于模型默认）；历史中不回传思考块；强制工具调用（any / 指定工具）降级为 `auto`，因为较新的 Claude 模型会拒绝强制调用；`max_tokens` 上限 128000，未设置时用 64000。

选择供应商后，点击 **导入模型** 获取可用模型列表。新模型默认不勾选；搜索并勾选需要的模型，点击 **导入** 才会保存。支持全选当前搜索结果和清空选择；取消不会导入任何模型。已有模型标记为“已导入”，不会重复添加、删除或改变启停状态。

导入后可以搜索、用开关逐个或全部启停（即时保存）、手动添加模型 ID。点模型名称打开编辑弹窗，可改显示名称，在“高级”中改上下文长度和推理强度；弹窗里的 **删除** 会先弹出确认框，确认后才移除该模型。命令面板的 **Fusion BYOK：选择模型导入** 也会打开此管理页面。

新导入或手动添加的模型默认上下文为 **272,000 tokens**，最大输出为 **131,072 tokens（128K）**；可逐个修改。已保存的显式数值不会被改写，实际可用上限仍取决于供应商支持的能力。

在 **预设** 页点 **新建预设**，填写名称，分别选择 Lead、Sidekick 及其档位。可以保存多个预设，之后编辑、改名、删除或选择。只有保存且当前可用的预设才生成模型入口，不再自动穷举组合。每个预设拥有独立、稳定的模型标识，按保存顺序显示在原生模型列表的 **我的 Fusion** 首位分组；第三方单模型仍可独立调用。

Lead／Sidekick 两份角色列表（**设置 → 预设可选模型**）独立管理，默认包含全部已启用的第三方模型及官方目录证明可用于对应角色的模型，只作为创建预设时的候选范围。从某角色移除模型不会删除供应商模型或影响另一角色。依赖不可用模型的预设保留并显示原因，不再发布可选入口；模型重新可用后恢复。官方模型不会因本地预设而获得账号原本没有的权限。

升级时会尝试把原先保存的默认组合准确还原为 **原默认组合** 预设；缺少官方目录信息时等待同步，不随意替换型号。明确删除全部预设后不会自动重建。保存配置不会自动重连或中断正在运行的会话。Devin 3.10 起，原生列表只显示界面目录与 Devin CLI 会话选项同时包含的模型，二者都只在打开新对话时刷新；因此当保存导致模型列表变化（新建、改名、删除预设，导入、启停模型等）时，插件会在约 1.5 秒后自动执行一次“新建对话”，让新列表生效。已开始的对话保持原有列表。如果列表仍未更新，可点控制面板右上角的 **重启 Devin**：确认后插件会退出 Devin 并自动重新打开（仅 macOS），这会中断所有窗口中正在进行的对话；若退出被取消，90 秒后放弃重开。CLI 的模型清单约 1 分钟内不会重复拉取，所以 1 分钟内连续修改时，自动刷新会顺延到缓存过期之后。

面板 **设置 → 官方模型显示** 列出 Devin 当前上报的原生模型，支持按名称或 UID 搜索，并标注官方不可用或不能用于预设。关掉开关只在本机把该条目从收到的目录中隐藏：不修改官方服务端配置，不改账号权限，其余官方条目保持原样。已隐藏的条目仍留在面板中便于恢复；重新打开开关只是删除本机的隐藏记录，模型要等 Devin 再次上报后才重新出现在列表里——扩展不会凭本地记录凭空补回官方已停发的条目。Devin 尚未上报任何官方模型时，该区域显示“等待 Devin 刷新官方模型列表”。

GPT-5/6、o1/o3/o4，以及 Claude Opus/Sonnet/Fable 4.6 及以上的基础模型 ID 在未设置档位时，自动提供 Low、Medium、High、XHigh、Max 预设；档位是否可用取决于供应商支持，带固定强度后缀的模型和其他系列继续使用供应商默认。可以在 **编辑模型 → 思考程度设置** 中手动填写供应商支持的档位，或选择不指定程度。预设来自模型 ID 规则，并非 `/models` 的能力检测；当前 `load / gpt-6-astra` 的 High 已通过真实请求验证。选择的档位会传入 Responses 的 `reasoning.effort` 或 Chat Completions 的 `reasoning_effort`。原来的默认档位 UID 保留，不指定参数时仍沿用供应商默认。

所有导入模型始终声明支持图片输入；早期配置中的关闭值同样按开启处理。这只是能力声明，不是供应商能力检测或保证。官方 Lead 的图片能力仍以官方目录为准。官方候选必须由已观察到的可用 Fusion 组合证明角色资格，并使用其实际执行通道；不再退回仅凭 SWE 通道识别型号。Fast Mode 变体、精确 UID 对应失败、序号或名称冲突、账号禁用、元数据歧义均不能授予资格。支持第三方／官方在两个角色中组合，但每个原生角色都必须满足上述条件和团队允许列表。没有收到官方目录时，仅含第三方模型的预设仍可使用。

已有 `~/.cwindsurf/providers.json` 时自动导入配置。原有 **Fusion BYOK：配置第三方 API** 命令现在也打开控制面板。

在原生模型列表的 **我的 Fusion** 分组直接选择预设，也可运行 **Fusion BYOK：选择 Fusion 预设** 或在面板预设行点 **设为默认**。选中的预设会被记住：当原生模型选择被重置为官方 Fusion 或清空时，扩展自动恢复有效的已记住预设；选择普通单模型不会被覆盖。改名保留选择标识；删除或停用导致预设不可用时不会强行恢复。

在控制面板 **设置** 页可独立开启两项自动继续选项（均默认关闭）：
- **服务商出错时自动重试**：当模型回复以“Provider response could not be completed”结尾或返回临时网络错误（如 HTTP 429/500/502/503/504 等）时，插件自动发送 `continue` 尝试继续，并在界面显示对应提示。关闭开关会立即取消后续自动继续；首次安装后请重新加载窗口并新建会话，以接入本地连接。重试间隔从 2 秒逐步增加，最长 30 秒；仅匹配指定失败提示，不判断任务是否完成，也不修复供应商故障。
- **待办没做完时自动继续**：检测到会话中存在未完成的结构化待办（Plan/Todo）时，正常回复后可自动发送 `continue`。每次自动续接（包括服务商错误后的续接）正常结束时，若待办内容和状态均未变化，就停止后续待办续接，避免已完成、受阻或等待确认的任务空转；重复上报、仅调整顺序或更换计划 ID 不算进展。待办确有变化时可以继续，全部完成或被停止打断时结束；手动发送消息可重新推进。插件不根据回复措辞猜测是否完成，也不保证业务语义上的真正完工；任务实际有进展但未更新待办时也会保守停止。无待办、非结构化计划或用户被询问权限时不会自动盲目继续。服务商错误重试仍由另一开关独立控制，使用计费模型时请留意额外用量。

免费账号无法调用的官方能力不会被解锁。插件根据角色管理和官方可用状态过滤 Fusion 目录，不修改官方权限。已有的锁定官方选择兼容回退仅在记住的预设两个角色都为第三方模型且仍有效时生效；建议直接选择自己命名的预设。原生选择器的固定收藏、最近使用等系统区域由 Devin 管理，插件保证注入的模型分组中“我的 Fusion”排在最前，不修改客户端应用。

## 目标（Goal，Beta）

> 测试版：还在收集真实使用反馈。控制面板的 **Goal** 标签页有同样的使用说明。

在 Devin 聊天框里直接输入 `/goal 要达成的目标`，目标就挂在**当前这个对话**上，并立即开始第一轮，不需要另开面板、选会话或分别填写验收标准。把“怎样算做完”直接写进这句话里，例如 `/goal 让 test/auth 里的测试全部通过，并保持 lint 干净`。插件也会把 `goal` 加进聊天框的命令菜单。

| 命令 | 作用 |
| --- | --- |
| `/goal <目标>` | 在当前对话启动目标；已有目标时替换旧目标（旧目标进入历史） |
| `/goal` | 查看当前目标、状态、已运行次数和最近进展 |
| `/goal pause` | 暂停自动推进 |
| `/goal resume` | 继续；如果已到运行上限，会再追加 10 次（总数最多 100） |
| `/goal clear` | 清除当前目标 |

每轮结束前，模型用插件提供的专用报告命令提交状态与证据：progress（有进展、还没做完）、waiting（需要你提供信息）、blocked（遇到具体阻碍）、complete（目标已达成并已验证）。提交 progress 后插件自动开始下一轮；提交 complete 后目标自动结束并进入历史。模型在回复文字里自称完成不会结束目标，必须通过报告命令提交证据。**报告内容来自模型，属于不可信数据**，请自行核对关键结果。

运行额度按已开始的轮数计算（默认 10 轮，最多 100 轮），不是 token 用量。以下情况会停下：达到运行上限、连续两轮没有提交报告、连续三轮证据完全相同、权限或询问请求、运行被取消或拒绝、会话断开、插件停用、窗口重新加载（需 `/goal resume`）。你在目标进行中手动发消息时，目标先让出这一轮，你的这轮结束后自动接着推进；目标处于 waiting / blocked 时，你回复后也会自动继续。用 `/goal pause` 暂停的目标只会在 `/goal resume` 后继续。

`/goal`、`/goal pause` 等查看与控制命令由插件直接处理，但为了让聊天界面正常显示回复，仍会让模型原样转述一句结果，会产生一次很短的模型调用。状态栏 **Goal** 与命令 **Fusion BYOK：目标（Goal）** 打开的面板只用于查看进度、证据和历史，以及暂停、恢复、归档。

会话归属以私有锁文件记录：同一对话若被其他窗口或进程占用，本窗口不会抢占。

以上行为在自动化测试中使用模拟的 ACP 连接验证；尚未对真实产品的实时协议字段做端到端验证。

## 上下文与性能

插件状态栏的 **上下文** 入口显示所选会话的主上下文占用比例，悬停查看简要数据，点击打开 **Fusion 上下文与性能** 数据面板。面板按会话选择，使用紧凑数据格展示上下文、本轮耗时（含等待）、最近已结束请求的速度和 token 明细；时间统一以秒（s）显示，缺失显示“—”，零仍显示零。配置主副模型单独标注，协议子代理不冒认为 Sidekick。状态栏提示不包含逐秒计时；相同数据不重复刷新，面板复用数据格与会话选项，选择不会随其它会话更新自动跳转。

只改插件，不修改 Devin 应用文件：原生输入框圆圈及其悬停内容保持原样，新增详情位于编辑器状态栏和插件面板，不是输入框内。所选会话不保证是当前聊天；上下文是最近一次真实上报，可能过时。观察器目前只接入之后注册的本地 Devin 连接，新建会话可能复用已有连接，不能保证解决接入失败；数据面板不再展示连接数、更新计数和大段说明；重载、断开和停用清除内存状态，不保存对话正文。性能数据无法按精确会话 ID 关联时不会借用其它会话；最近请求不一定属于当前轮次或主模型。尚未上报的子模型用量不能凭配置容量推算。

## 保存和更新

控制面板 **设置** 页的 **插件更新** 从 `kuobibulaien/devin-fusion-byok` 的 GitHub Releases 检查最新正式版；启动后检查一次，同一窗口之后每 6 小时检查。可关闭自动检查、忽略某个版本，或运行 **Fusion BYOK：检查更新** 手动检查。它是定期检查，不需要自建服务器；不上传供应商配置、密钥或对话。GitHub 不可达或限流时显示检查失败，不会误报最新版，也不会将本地较新的开发版降级。

点击 **下载并安装** 后还需确认。仅接受固定仓库、对应版本名称的 VSIX；下载受超时和 50 MiB 大小限制，并校验 GitHub 返回的 SHA-256、文件大小、包内两份描述文件中的插件身份和版本。缺少安全校验信息时只提供发布页面手动安装。自动安装目前仅接入 macOS 的 Devin 自带命令行安装入口，其退出成功不代表新窗口已验收；不自动重载，不修改用户配置，新窗口或用户主动重载后才加载新版。首次获得此功能仍需要手动安装含更新器的版本。

发版时需要创建正式 Release，标签使用 `v主版本.次版本.修订号`，附加 `devin-fusion-byok-版本号.vsix`；包版本必须一致，插件身份继续为 `local.devin-fusion-byok`，并确保 GitHub 资产接口返回有效的 SHA-256 digest 和大小。只有源码或标签、没有安装包的版本不能一键安装。本轮尚未真实安装、重载或验证完整在线升级过程。

密钥仅保存在用户私有配置文件（权限 0600）。日志仅记录模型名、工具名和连接状态。通过 `devin.acp.agentEnv` 给 Devin CLI 设置 `WINDSURF_API_SERVER_URL`，只连接本机服务；本机服务仍通过正常 HTTPS 访问官方接口。不安装证书，不修改系统代理。

Devin 常规应用更新不会覆盖用户扩展目录。扩展每次启动重新寻找内置扩展和语言服务。若 Devin 未来移除当前运行时接口，扩展会报告错误；这不等于保证兼容所有未来版本。

扩展版本更新后，本机连接服务在下次启动时平滑替换。如果同目录下的旧版服务仍在处理请求，扩展会先直接沿用旧服务完成启动，升级在后台继续等待；旧服务空闲后才做带归属校验的停机替换，正在进行的请求不会被强行中断，期间日志记录 `runtime-update-pending`。属于其他配置目录或更新版本的服务不会被视为可复用，仍按原逻辑报错。

## 停用

先运行 **Fusion BYOK：停用并恢复连接**，再卸载扩展。停用会撤回所有窗口的模型注入，并恢复本扩展设置的 CLI 环境项和默认 Fusion 组合。环境项只在当前值仍等于插件所写值时恢复；默认模型有原始备份且当前仍属于本插件时才恢复，保留用户之后选择的原生模型。关闭或重新加载普通窗口只清理该窗口的注入，不会撤回其他窗口所需的连接设置。停用后可通过 **配置第三方 API** 重新启用；单独刷新模型不会重新启用。

直接卸载也会尝试恢复已记录的设置，兼容 JSONC 注释和尾随逗号，并保留原设置副本。若设置内容有歧义、正在被修改或无法安全写入，脚本不覆盖它，并把恢复记录保存在用户 `settings.json.fusion-byok-restore-pending.json`。卸载脚本的执行时间由 Devin 限制；先运行恢复命令更可靠。

已经启动的会话沿用启动时的环境；停用后请新建会话使用原生配置。本地服务不会因关闭一个窗口或卸载而强行终止正在进行的请求。
